# Gym management system

A Django REST Framework API for managing gym operations.

The backend provides RESTful API endpoints for managing members, 
trainers, exercises, workout plans, training sessions, and attendance records.

---

## Features

- REST API architecture
- CRUD operations for all resources
- Member management
- Trainer management
- Exercise management
- Workout plan management
- Session scheduling
- SQLite database
- API serialization using Django REST Framework

---

## Technologies Used

- Python
- Django REST Framework
- SQLite

---

## Install dependencies
```bash
pip install -r requirements.txt
```
---

## Running the server
```bash
python manage.py runserver
```
